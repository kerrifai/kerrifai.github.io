Featured Projects

  • Plataforma de visualización de datos de IA: Este proyecto funciona como una plataforma de análisis y visualización de datos asistida por IA diseñada para generar información automática, gráficos explicativos y análisis exploratorios a partir de uno o más conjuntos de datos (CSV).
  • Asistente de PDF's: Este proyecto implementa una aplicación web interactiva creada con Python, Streamlit y LangChain para cargar uno o varios archivos PDF, extraer automáticamente su contenido, generar explicaciones estructuradas y realizar preguntas y respuestas basadas exclusivamente en el texto del PDF.
  • Informe ETL: canalización de datos automatizada para inteligencia empresarial y análisis: Este proyecto implementa una canalización ETL (Extracción-Transformación-Carga) orientada a la producción diseñada para procesar datos comerciales sin procesar, almacenarlos en una base de datos estructurada y generar conjuntos de datos analíticos listos para usar para Power BI.
  • Panel de monitorizacion para sensores industriales (Qt + PySide6): Este proyecto visualiza una aplicación de escritorio desarrollada en Python y PySide6 (Qt) que funciona como un sistema SCADA/HMI local. Permite la adquisición, visualización, almacenamiento y análisis en tiempo real de datos de sensores provenientes de archivos CSV/JSON.
